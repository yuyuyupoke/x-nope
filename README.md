# x-nope

X（旧 Twitter）のタイムラインで、**ポストにカーソルを乗せて `x` キーを押すだけ**で「興味なし」を送る Chrome 拡張。

見たくない動画や投稿をその場で消し、同時に X のおすすめに「これは要らない」と伝えて、似た投稿が出にくくなるようにする。

## インストール（3分）

1. **[x-nope.zip をダウンロード](https://github.com/yuyuyupoke/x-nope/releases/latest/download/x-nope.zip)** して解凍する。`x-nope` というフォルダができる
2. その **`x-nope` フォルダを、消さない場所へ移動する**（例: 「書類」フォルダ）
   - Chrome はこのフォルダを直接読み込んで動く。ダウンロードフォルダに置いたまま後で掃除すると、拡張も動かなくなる
3. Chrome のアドレスバーに `chrome://extensions` と入力して開く
4. 右上の **「デベロッパー モード」をオン**にする
5. 左上の **「パッケージ化されていない拡張機能を読み込む」** を押し、手順 2 の `x-nope` フォルダを選ぶ
6. [x.com](https://x.com) を開く（すでに開いているタブは再読み込みする）

画面右下に **「x-nope が有効になりました」** と出れば完了。

> Chrome で動作を確認している。Edge や Brave などの Chromium 系ブラウザも同じ手順で入るはず（未検証）。ブラウザは最新版にしておくこと。

## 使い方

| 操作 | 動作 |
|---|---|
| ポストにカーソルを乗せて `x` | 「興味なし」を送り、そのポストを消す |
| `⌘Z`（Windows は `Ctrl+Z`） | 直前に消したポストを表示に戻す（送った「興味なし」は取り消せない） |

押したあと、右下に結果が出る:

| 表示 | 意味 |
|---|---|
| `興味なし 送信中…` | 処理中 |
| `✓ 興味なし 送信を確認` | X に届いた。これで完了 |
| `⚠️ 興味なしを送れていない` | 届かなかった。ポストは消えたままになる（下の「うまく動かないとき」へ） |

- 文字入力中（返信欄・検索欄など）は反応しない
- 連打してよい。1件ずつ順番に送る（長押しでの連発はしない）
- 消したポストは、スクロールで戻ってきても消えたまま
- 自分のポストには「興味なし」の項目がないので、何も起きない

## 仕組み

あなたが手でやる操作と同じことを自動でやっている。ポストの「…」メニューを開き、「興味がない」を押して、メニューを閉じる。メニューは一瞬だけ透明にしているので、画面には出ない。

押したポストはすぐ見えなくなり、送信が終わった時点（通常1秒以内）で隙間が詰まる。

X が公開しているおすすめのアルゴリズム（[xai-org/x-algorithm](https://github.com/xai-org/x-algorithm)）では、「興味なし」はマイナスの評価として使われる。つまり押すほど、似た投稿が出にくくなる。

ブロック・ミュート・報告は自動化しない。これらを大量に自動で行うと、X の自動化ルールに触れてアカウントが凍結される恐れがあるため。

## プライバシーと安全

- **外部への通信はしない。** この拡張がデータを送る先はどこにもない。「興味なし」は、X の画面上のボタンを押すことで X に届く
- **動くのは x.com と twitter.com の中だけ。** 他のサイトや閲覧履歴には触れない。manifest で追加の権限（`permissions`）は何も要求していない
- **誤爆しない作り。** メニューの項目は文字で確かめて押す。「ブロック」「ミュート」「報告」「フォロー」「削除」などの語を含む項目は絶対に押さない。「興味なし」が見つからなければ、何も押さずにメニューを閉じる
- **送れたかを確かめる。** 押しただけでは成功扱いにしない。`net.js` が x.com のページ内の通信を見ていて、押した直後に「興味なし」の送信（X の `feedback.json`）があり、成功が返ってきたときだけ ✓ を出す。見ているのは「操作名」と「成否」だけで、通信の中身は読まないし保存もしない
- **記録は x.com のブラウザ内に残る。** 消したポストの ID、送信ログ、設定は、ブラウザ内にある x.com 用の保存領域（localStorage）に入る。そのため X のページ側からも読める。ただ、X は「興味なし」を受け取っている側なので、これで X に新しく知られることはない
- コードは全部で数百行。気になる人は [`content.js`](content.js) と [`net.js`](net.js) を読んでから入れてほしい

## 注意

X とは無関係の個人ツール。手でメニューを押すのと同じ操作を1件ずつ行うだけだが、X の仕様変更で突然動かなくなることはあるし、規約上のリスクもゼロとは言えない。**自己責任で使ってほしい。**

## うまく動かないとき

**右下に何も出ない / `x` を押しても反応しない**
- `chrome://extensions` で x-nope がオンになっているか確認する
- x.com のタブを再読み込みする
- 「x-nope が有効になりました」は最初の1回しか出ない。2回目以降は出なくて正常

**`⚠️ 興味なしを送れていない` の下に「「興味なし」の項目が見つからない」と出る**
- X 側でメニューの文言が変わった可能性がある。[Issue](https://github.com/yuyuyupoke/x-nope/issues) で教えてほしい（自分で直したい人は下の「上級者向け」）

**`⚠️ 興味なしを送れていない` の下に「送信リクエストが観測されなかった」と出る**
- x.com を再読み込みしてもう一度試す。続くようなら Issue で教えてほしい

## アップデート

1. 新しい [x-nope.zip](https://github.com/yuyuyupoke/x-nope/releases/latest/download/x-nope.zip) をダウンロードして解凍する
2. 今使っている `x-nope` フォルダの中身を、新しいものに丸ごと入れ替える（フォルダの場所は変えない）
3. `chrome://extensions` で x-nope の 🔄（再読み込み）を押し、x.com のタブも再読み込みする

更新の通知が欲しい人は、このページ右上の **Watch → Custom → Releases** にチェックを入れておくと届く。

## アンインストール

`chrome://extensions` で x-nope の「削除」を押し、`x-nope` フォルダを捨てる。

## 上級者向け

ここから下は、x.com を開いた状態で開発者ツールのコンソール（Mac: `⌘⌥J` / Windows: `Ctrl+Shift+J`）に貼り付けて使う。

### 設定

```js
localStorage.setItem('xnope.key', 'q')                          // 押すキーを変える（既定: x。英数字1文字）
localStorage.setItem('xnope.debug', '1')                        // 詳しいログを出す
localStorage.setItem('xnope.labels', JSON.stringify(['...']))   // 「興味なし」として押してよい文言を追加する
```

押すキーは、X 純正のショートカット（`b`=ブロック、`u`=ミュート、`l`=いいね など）と重なるものには変えられない。指定しても `x` のままになる。

「興味なし」の項目が見つからなかったときは、コンソールに実際のメニュー項目の一覧が出る。その中の正しい文言を `xnope.labels` に登録すれば、次から動く。ただし「ブロック」などの危険な語を含む文言は、登録しても押さない。

### 送信ログを見る

送った結果は最大300件まで残る。

```js
console.table(JSON.parse(localStorage.getItem('xnope.log') || '[]').map(e => ({
  時刻: new Date(e.t).toLocaleString(),
  結果: e.ok ? '✓ 送信確認' : '✗ ' + (e.reason || ''),
  操作: e.op,
  status: e.status,
  投稿: 'https://x.com/i/status/' + e.id,
})))
```

消したポストの URL 一覧:

```js
JSON.parse(localStorage.getItem('xnope.killed') || '[]').map(id => 'https://x.com/i/status/' + id)
```

### 記録を消す

```js
Object.keys(localStorage).filter(k => k.startsWith('xnope.')).forEach(k => localStorage.removeItem(k))
```

## 開発

```
manifest.json       MV3 マニフェスト
net.js              ページ側で動き、X へ実際に飛んだリクエストを観測する
content.js          本体（カーソル追跡・キー処理・送信キュー・送信確認・非表示・トースト）
style.css           送信中のメニュー隠し、非表示のセル、トースト
test/match.test.js  メニュー項目の照合が誤爆しないことの検証
scripts/zip.sh      配布用 zip を作る
```

```sh
npm test        # 照合ロジックのテスト
npm run zip     # dist/x-nope.zip を作る
```

リリースするときは `manifest.json` と `package.json` の version を上げてから:

```sh
npm test && npm run zip && gh release create v0.x.y dist/x-nope.zip
```

zip のファイル名を `x-nope.zip` のまま保てば、README のダウンロードリンクは常に最新版を指す。
